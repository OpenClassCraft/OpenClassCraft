# അധ്യാപകർക്കുള്ള ദ്രുതാരംഭ ഗൈഡ്: ആദ്യ OpenClassCraft പാഠം

ഉദ്ദേശിച്ചിരിക്കുന്നത്: 5–8 ക്ലാസുകളിലെ Founding School Beta · സമയം: 45 മിനിറ്റ്

പഠനലക്ഷ്യം: ക്രമത്തിൽ തയ്യാറാക്കിയ റോബോട്ട് പ്രോഗ്രാം വിദ്യാർത്ഥികൾ മുൻകൂട്ടി പ്രവചിക്കുകയും പ്രവർത്തിപ്പിക്കുകയും പിശക് തിരുത്തുകയും ചെയ്യുക.

> **ഭാഷയെക്കുറിച്ചുള്ള കുറിപ്പ്:** സോഫ്റ്റ്‌വെയറിലെ ബട്ടണുകളുടെ പേരുകൾ ഇപ്പോൾ ഇംഗ്ലീഷിലാണ്. അതിനാൽ അമർത്തേണ്ട ലേബലുകൾ ഈ ഗൈഡിലും ഇംഗ്ലീഷിൽ തന്നെയാണ് നൽകിയിരിക്കുന്നത്.

## ക്ലാസ് തുടങ്ങുന്നതിന് മുമ്പ്

സ്കൂൾ അംഗീകരിച്ച OpenClassCraft പാക്കേജ് വിശ്വസനീയമായ പ്രാദേശിക നെറ്റ്‌വർക്കിൽ മാത്രം ഉപയോഗിക്കുക. Founding Beta ഘട്ടത്തിൽ യഥാർത്ഥ വിദ്യാർത്ഥി പേരുകൾക്കു പകരം ക്ലാസ് alias അല്ലെങ്കിൽ ഗ്രൂപ്പ് പേരുകൾ മാത്രം ഉപയോഗിക്കണം. Player name, chat, board, Guide, world name, project, Teacher Console എന്നിവയിൽ വിദ്യാർത്ഥികളുടെ യഥാർത്ഥ പേര് അല്ലെങ്കിൽ സ്വകാര്യവിവരങ്ങൾ നൽകരുത്.

ആവശ്യമായത്:

- ഒരു അധ്യാപക കമ്പ്യൂട്ടറും പരിശോധിച്ച കുറഞ്ഞത് ഒരു വിദ്യാർത്ഥി കമ്പ്യൂട്ടറും;
- എല്ലാ കമ്പ്യൂട്ടറുകളിലും ഒരേ അംഗീകരിച്ച OpenClassCraft പതിപ്പ്;
- വിശ്വസനീയമായ സ്കൂൾ LAN;
- അധ്യാപകൻ തിരഞ്ഞെടുത്ത game port-ഉം LAN discovery-ക്കുള്ള UDP port `29999`-ഉം;
- ക്ലാസിനുള്ള സ്വകാര്യ server password; കൂടാതെ
- പരീക്ഷണത്തിനായി ഉപയോഗിക്കാവുന്നതോ backup എടുത്തതോ ആയ ഒരു lesson world.

LAN discovery പ്രവർത്തിച്ചില്ലെങ്കിൽ ഉപയോഗിക്കാൻ അധ്യാപക കമ്പ്യൂട്ടറിന്റെ private LAN address-ഉം തിരഞ്ഞെടുത്ത game port-ഉം ക്ലാസിനുള്ളിൽ സുരക്ഷിതമായി സൂക്ഷിക്കുക. അവ public issue-ൽ പ്രസിദ്ധീകരിക്കരുത്.

## 1. World തയ്യാറാക്കി പരിശോധിക്കുക

1. **Start Game → Singleplayer** തുറക്കുക.
2. **New World** തിരഞ്ഞെടുക്കുക. `Robot Paths 01` പോലെയുള്ള വ്യക്തിപരമല്ലാത്ത പേര് നൽകുക. OpenClassCraft game ഉപയോഗിച്ച് world സൃഷ്ടിക്കുക.
3. World തിരഞ്ഞെടുത്ത് ഒരിക്കൽ **Play Game** അമർത്തുക.
4. <kbd>I</kbd> അമർത്തി catalog തുറക്കുക. **Programming** വിഭാഗത്തിൽ Robot Spawner, START, Move Forward, Turn Right, Stop എന്നിവ ഉണ്ടെന്ന് ഉറപ്പാക്കുക.
5. World ശരിയായി അടച്ചശേഷം സ്കൂൾ അംഗീകരിച്ച സ്ഥലത്ത് backup എടുക്കുക.

## 2. ക്ലാസ് host ചെയ്യുക

1. **Singleplayer**-ൽ പരിശോധിച്ച world തിരഞ്ഞെടുക്കുക.
2. **Host Server**, **Educator** എന്നിവ enable ചെയ്യുക.
3. അധ്യാപകന്റെ classroom alias, തിരഞ്ഞെടുത്ത port, സ്വകാര്യ password എന്നിവ നൽകുക.
4. **Host Game** അമർത്തി host പ്രവർത്തിച്ചുകൊണ്ടിരിക്കട്ടെ.
5. ഒരു വിദ്യാർത്ഥി കമ്പ്യൂട്ടറിൽ **Start Game → Local Servers** തുറന്ന് **Refresh** അമർത്തുക.
6. അധ്യാപകന്റെ class തിരഞ്ഞെടുക്കുക. Student alias-ഉം password-ഉം നൽകി **Join Server** അമർത്തുക.
7. Server കണ്ടെത്താനാകുന്നില്ലെങ്കിൽ അധ്യാപക കമ്പ്യൂട്ടറിന്റെ private LAN address-ഉം തിരഞ്ഞെടുത്ത game port-ഉം നേരിട്ട് നൽകുക.

LAN discovery UDP port `29999` ഉപയോഗിക്കുന്നു. Game അധ്യാപകൻ തിരഞ്ഞെടുത്ത മറ്റൊരു port ഉപയോഗിക്കുന്നു. Guest-network isolation അല്ലെങ്കിൽ firewall കാരണം discovery തടയപ്പെട്ടാലും manual join പ്രവർത്തിക്കാം.

## 3. ആദ്യ പ്രോഗ്രാം നിർമ്മിക്കുക

തടസ്സമില്ലാത്ത നിലത്ത്:

1. **Programming** catalog-ൽ നിന്ന് **Robot Spawner**, **START**, **Move Forward**, **Turn Right**, **Stop** എന്നിവ എടുക്കുക.
2. Robot Spawner നിലത്ത് ഉപയോഗിച്ച് robot സൃഷ്ടിക്കുക.
3. `START` block സ്ഥാപിക്കുക.
4. START-ന്റെ ഉടൻ കിഴക്ക് ഭാഗത്ത് (world `+X`) `Move Forward`, തുടർന്ന് `Turn Right`, തുടർന്ന് `Stop` എന്ന ക്രമത്തിൽ ഒരേ വരിയിൽ സ്ഥാപിക്കുക.
5. Robot-ൽ നിന്ന് 32 nodes പരിധിക്കുള്ളിൽ നിന്നുകൊണ്ട് START-ൽ right-click ചെയ്യുക.
6. Robot ചെയ്യുന്ന ഓരോ പ്രവർത്തിയും നിരീക്ഷിക്കുക.

START പ്രവർത്തിപ്പിച്ച വിദ്യാർത്ഥിക്ക് ഏറ്റവും അടുത്ത robot ആണ് തിരഞ്ഞെടുക്കപ്പെടുന്നത്. അതിനാൽ ഓരോ ഗ്രൂപ്പിനടുത്തും ആവശ്യമായ robot മാത്രം വയ്ക്കുക.

| സമയം | അധ്യാപകൻ ചെയ്യുന്നത് | വിദ്യാർത്ഥികൾ ചെയ്യുന്നത് |
| --- | --- | --- |
| 0–5 മിനിറ്റ് | ലക്ഷ്യവും അടിസ്ഥാന controls-ഉം കാണിക്കുക | Alias ഉപയോഗിച്ച് join ചെയ്ത് പ്രവർത്തന സ്ഥലത്തെത്തുക |
| 5–10 മിനിറ്റ് | START → MOVE → TURN → STOP കാണിക്കുക | Robot അവസാനം എവിടെയായിരിക്കുമെന്നും ഏത് ദിശയിലായിരിക്കുമെന്നും പ്രവചിക്കുക |
| 10–22 മിനിറ്റ് | ഓരോ ടീമിനും ചെറിയ target path നൽകുക | ഒരു sequence നിർമ്മിച്ച് പ്രവർത്തിപ്പിക്കുക |
| 22–32 മിനിറ്റ് | ഒരു block തെറ്റായോ കുറവായോ ഉള്ള ഉദാഹരണം നൽകുക | ലഭിച്ച ഫലം വിശദീകരിച്ച് ഒരു block മാത്രം മാറ്റുക |
| 32–40 മിനിറ്റ് | ടീമുകൾ challenge കൈമാറാൻ പറയുക | മറ്റൊരു ടീമിന്റെ program run ചെയ്യുകയോ debug ചെയ്യുകയോ ചെയ്യുക |
| 40–45 മിനിറ്റ് | ഒരു വിശദീകരണം ചോദിച്ച് session അവസാനിപ്പിക്കുക | Work save ചെയ്ത് server വിടുക; എന്താണ് മാറ്റിയതെന്ന് പറയുക |

ഓരോ പ്രവർത്തനത്തിലും ഈ അഞ്ച് ചോദ്യങ്ങൾ ഉപയോഗിക്കുക:

1. **പ്രവചിക്കുക:** Robot എന്ത് ചെയ്യും?
2. **പ്രവർത്തിപ്പിക്കുക:** യഥാർത്ഥത്തിൽ എന്ത് സംഭവിച്ചു?
3. **പിശക് കണ്ടെത്തുക:** പ്രതീക്ഷിച്ചതിൽ നിന്നുള്ള വ്യത്യാസത്തിന് കാരണമായ instruction ഏത്?
4. **മാറ്റുക:** ഒരു block മാത്രം മാറ്റുക.
5. **വിശദീകരിക്കുക:** അടുത്ത run വ്യത്യസ്തമാകാൻ കാരണം എന്ത്?

## 5. സുരക്ഷിതമായി session അവസാനിപ്പിക്കുക

1. വിദ്യാർത്ഥികളോട് editing നിർത്തി server-ൽ നിന്ന് leave ചെയ്യാൻ പറയുക.
2. Hosted world save ചെയ്ത് ശരിയായി അടയ്ക്കുക.
3. സ്കൂൾ അംഗീകരിച്ച സ്ഥലത്ത് world backup എടുക്കുക.
4. “നാല് ടീമിൽ മൂന്ന് ടീമുകൾ checkpoint എത്തി” പോലെയുള്ള കൂട്ടമായ പുരോഗതി മാത്രം രേഖപ്പെടുത്തുക.
5. പ്രശ്നമുണ്ടായാൽ app version, ബാധിച്ച device-ന്റെ role, ചെയ്ത action, പ്രതീക്ഷിച്ച ഫലം, ലഭിച്ച ഫലം, workaround എന്നിവ രേഖപ്പെടുത്തുക. Report പങ്കിടുന്നതിന് മുമ്പ് username, token, IP address, private file path എന്നിവ നീക്കം ചെയ്യുക.

## ഉടൻ session നിർത്തേണ്ട സാഹചര്യങ്ങൾ

- World save ആകുന്നില്ല അല്ലെങ്കിൽ corrupt ആകുന്നു;
- വിദ്യാർത്ഥിക്ക് teacher records അല്ലെങ്കിൽ നിയന്ത്രിക്കാനാകാത്ത destructive tools ലഭിക്കുന്നു;
- വിദ്യാർത്ഥി/സ്കൂൾ സ്വകാര്യവിവരം, password, network വിവരം, bridge token എന്നിവ പ്രതീക്ഷിക്കാതെ കാണുന്നു;
- ഒരേ crash കാരണം ക്ലാസ് തുടരാനാകുന്നില്ല; അല്ലെങ്കിൽ
- Package checksum പ്രസിദ്ധീകരിച്ച checksum-നോട് പൊരുത്തപ്പെടുന്നില്ല.

Software നിർത്തിയ സമയത്ത് ഉപയോഗിക്കാൻ offline backup activity തയ്യാറാക്കുക. Security അല്ലെങ്കിൽ privacy പ്രശ്നം public issue-ൽ ഇടാതെ project-ന്റെ private vulnerability reporting വഴി അറിയിക്കുക.

## വിദ്യാർത്ഥികളോട് വ്യക്തമാക്കേണ്ട ഇപ്പോഴത്തെ പരിമിതികൾ

- **Educator** switch ഇപ്പോഴും ശക്തമായ teacher permission സംവിധാനം അല്ല.
- `ELSE`, `WHILE Clear` പ്രവർത്തനം പരീക്ഷണ ഘട്ടത്തിലാണ്; loop, condition എന്നിവ ഇപ്പോൾ അടുത്ത instruction-നെ മാത്രം ബാധിക്കുന്നു.
- World Edit Wand-ന് undo ഇല്ല; backup world-ൽ മാത്രം ഉപയോഗിക്കുക.
- School network LAN discovery തടയാം; manual join fallback ആയി ഉപയോഗിക്കാം.
- ഇത് alpha/beta software ആണ്. ചിലപ്പോൾ workaround ഉപയോഗിക്കുകയോ session മാറ്റിവയ്ക്കുകയോ വേണ്ടിവരും.

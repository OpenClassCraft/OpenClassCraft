# Starter Chemistry Lab — teacher notes

## Learning goal

Students use a particle model to describe water as two hydrogen atoms combined with one oxygen atom.

## Suggested 35-minute lesson

1. Assign one marked bench to each group and keep digging disabled.
2. Students join with `/occ_join CODE`, read the lab board, and identify the input atoms.
3. Students use the Chemistry Lab node to create water.
4. Each group records the atom ratio and explains the result in words or a screenshot.
5. Review incoming chemistry submissions with a method-and-explanation rubric.

## Extension

Ask students what changes when the number of available hydrogen or oxygen atoms is limited. Treat the activity as a model, not a substitute for a supervised physical laboratory.

The Console's **Reset** action archives the used lab world before rebuilding the clean template.

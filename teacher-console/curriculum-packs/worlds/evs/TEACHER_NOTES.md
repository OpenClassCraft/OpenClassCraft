# Starter Environmental Studies World — teacher notes

## Learning goal

Students compare model habitat zones, identify an environmental pressure, and justify a low-impact improvement.

## Suggested 40-minute lesson

1. Begin in read-only mode and send groups through the water, dry-soil, and habitat markers.
2. Students record one benefit, one pressure, and one affected living thing per zone.
3. Discuss which changes would solve a problem without creating a larger one.
4. Advance to a tightly controlled build stage for small group prototypes.
5. Photograph the proposal, attach it to the portfolio, and review the justification.

## Safeguards

The activity is a simplified model. Pair it with local examples and avoid presenting one simulated habitat as universal. Keep digging disabled unless soil removal is part of the explicit learning goal.

Use Snapshot before the build stage. Reset archives the current model and creates a clean template.

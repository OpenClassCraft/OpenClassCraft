# Starter Coding World — teacher notes

## Learning goal

Students construct, test, and debug a sequence of visual coding blocks that moves a robot to the finish marker.

## Suggested 35-minute lesson

1. Start the Teacher Console bridge and advance to the exploration stage.
2. Students join with `/occ_join CODE`, read the blackboard, and identify the sample blocks.
3. Advance to the build stage and allow the listed coding blocks.
4. Students place a robot and build a START → MOVE/TURN → STOP sequence.
5. Ask students to submit a robot result and explain one debugging change.

## Assessment evidence

- A valid sequence reaches the lesson marker.
- The student can explain order, direction, and one correction.
- Use a four-point “Correct method / Debugging explanation” rubric.

# Starter Science Observation World — teacher notes

## Learning goal

Students use consistent observation prompts to compare sand, gravel, and clay models and support a conclusion with evidence.

## Suggested 30-minute lesson

1. Keep the first stage read-only while students visit each marked zone.
2. Ask every group to record texture, particle size, and a prediction using the same format.
3. Advance to an optional build stage if students should construct a small comparison model.
4. Attach one screenshot or note to each student's portfolio.
5. Discuss the limits of a block-world model compared with real samples.

## Assessment evidence

- Three observations collected consistently.
- A claim linked to at least one observation.
- A statement about model limitations.

Snapshot the world before allowing building. Reset always archives the current copy.
